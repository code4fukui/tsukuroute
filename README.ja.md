# tsukuroute
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

tsukuroute は Code for FUKUI が開発したオープンソースプロジェクトで、ルートの計画と管理を便利に行うことができます。

日本語版:

## 機能

- ルートの計画と最適化
- 共同ルート共有
- 地図サービスとの統合
- 詳細なルート情報と方向

## 使用方法

tsukurouteを使用するには、以下の手順に従ってください:

1. リポジトリをクローンします:
   ```
   git clone https://github.com/CodeForFUKUI/tsukuroute.git
   ```
2. 必要な依存関係をインストールします。
3. アプリケーションを実行します。

詳細な導入方法と使用方法については、プロジェクトのドキュメントをご確認ください。
